Política de privacidade do Alicerce ERP

O Alicerce ERP é um sistema de gestão de uso interno, operado pelo próprio titular da conta para as empresas dele. Não é oferecido ao público.

Dados do Google acessados

Com a sua autorização, o Alicerce acessa somente os arquivos do Google Drive que ele mesmo cria ou que você abre nele (escopo drive.file), dentro da pasta "Alicerce". O objetivo é arquivar documentos fiscais e financeiros (notas, boletos, recibos, comprovantes) e vinculá-los aos lançamentos.

Uso e compartilhamento

Os dados são usados apenas para essa finalidade. Não são vendidos, não são compartilhados com terceiros e não são usados para publicidade nem para treinar modelos de IA. O banco de dados fica num projeto Supabase próprio do titular. A autorização de acesso ao Drive fica guardada como segredo do servidor.

Guarda e exclusão

Os documentos são mantidos pelo prazo de guarda fiscal (no mínimo 5 anos). Você pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.

O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
